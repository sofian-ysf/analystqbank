```

Blog Posts → Mock Exam Page
Mock Exam → Practice Questions
```

**Implementation:**
- Add "Related Resources" section to each blog post
- Create topic hubs (e.g., "Ethics Hub" linking all ethics content)
- Add footer links to main study tools

### 3.2 Schema Markup

Add structured data to improve SERP appearance:

```json
// FAQ Schema for Mock Exam Page
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "How many questions are on the CFA Level 1 exam?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "The CFA Level 1 exam contains 180 multiple-choice questions split into two 2.25-hour sessions."
    }
  }]
}

// Course Schema for Practice Questions
{
  "@context": "https://schema.org",
  "@type": "Course",
  "name": "CFA Level 1 Practice Questions",
  "description": "Free CFA Level 1 practice questions covering all 10 topics",
  "provider": {
    "@type": "Organization",
    "name": "AnalystTrainer"
  }
}
```

### 3.3 Speed Optimization

- Compress images
- Enable caching
- Minify CSS/JS
- Target Core Web Vitals score > 90
